User Data Fetch Web Application

This project is a simple web application built using HTML, CSS, and JavaScript that demonstrates how to fetch and display data dynamically using a REST API. The application allows users to retrieve data with a button click and clear it from the UI when needed.
Technologies Used
HTML5
CSS3
JavaScript (DOM Manipulation)
REST API (Fetch API)
Features
🔹 Fetch Data
On clicking the "Get Data" button, the application fetches data from an API.
The retrieved data is displayed dynamically on the webpage.
Uses JavaScript DOM manipulation to update UI in real-time.
🔹 Clear Data
On clicking the "Erase" button, the displayed data is removed from the screen.
Ensures a clean and interactive user experience.
